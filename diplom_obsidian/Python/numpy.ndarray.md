`ndarray` (N-dimensional array) — это **основной контейнер данных** в NumPy. Это не список Python, а **блок непрерывной памяти** с одинаковым типом данных.

```python
### 1. **Тип данных (`dtype`)**

python

arr_int = np.array([1,2,3], dtype=np.int32)    # 4 байта на элемент
arr_float = np.array([1,2,3], dtype=np.float64) # 8 байт на элемент
arr_uint8 = np.array([0,255], dtype=np.uint8)   # 1 байт

В вашем коде:

- `int32` — для X и сырых АЦП (экономия памяти, скорость)
    
- `float64` — для фильтра (точность вычислений)
    

### 2. **Форма (`shape`)**

python

arr = np.zeros(1000)        # shape: (1000,) — одномерный
mat = np.zeros((100, 100))  # shape: (100, 100) — матрица
cube = np.zeros((10, 10, 10)) # 3D массив

### 3. **Шаги (`strides`)**

python

arr = np.array([1,2,3,4,5], dtype=np.int32)
# strides = (4,)  — чтобы перейти к следующему элементу, сдвиг на 4 байта

---

## Почему `ndarray` быстрее списков?

|Операция|Список Python|`ndarray`|
|---|---|---|
|`a + b`|поэлементно через цикл|SIMD-инструкции процессора|
|`a * 2`|создает новые объекты|меняет байты на месте|
|Доступ|проверка типа на каждом шаге|прямой доступ по адресу|

**Пример**:

python

# Python list — медленно (интерпретатор)
lst = list(range(1000000))
result = [x * 2 for x in lst]  # ~50 мс
# NumPy — быстро (скомпилированный C)
arr = np.arange(1000000)
result = arr * 2  # ~2 мс

## Важные операции с `ndarray`

### Создание

python

np.zeros(1000, dtype=np.int32)    # нули
np.ones(1000)                     # единицы
np.arange(0, 100, 2)              # [0, 2, 4, ..., 98]
np.linspace(0, 1, 100)            # 100 точек от 0 до 1
np.empty(1000)                    # без инициализации (быстрее)

### Индексация и срезы (без копирования!)

python

arr = np.arange(10)
slice_arr = arr[2:5]  # это view (ссылка), не копия!
slice_arr[0] = 999     # изменит оригинальный arr
# Чтобы скопировать:
copy_arr = arr[2:5].copy()

### Универсальные функции (ufunc)

python

arr = np.array([1, 2, 3, 4])
np.sqrt(arr)      # [1, 1.414, 1.732, 2]
np.sin(arr)       # тригонометрия
np.exp(arr)       # экспонента
arr + 10          # поэлементное сложение
arr * arr         # поэлементное умножение

### Агрегация

python

arr.sum()         # сумма всех элементов
arr.mean()        # среднее
arr.max()         # максимум
arr.std()         # стандартное отклонение
```
